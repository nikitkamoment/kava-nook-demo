# Виджет расписания для iPhone

Показывает, какой сейчас урок, сколько минут до его конца, что дальше. После уроков и в выходные показывает первый урок ближайшего учебного дня.

## Установка на телефон (около 5 минут)

1. Установи бесплатное приложение **Scriptable** из App Store.
2. Открой файл `schedule-widget.js` и скопируй весь текст.
3. В Scriptable нажми **+**, вставь текст и назови скрипт, например «Расписание».
4. Нажми **▶** в Scriptable: должно открыться превью виджета.
5. На главном экране долго нажми на пустое место, затем **+**, выбери **Scriptable** и размер виджета (маленький или средний). Нажми на добавленный виджет, в поле **Script** выбери «Расписание».
6. Для экрана блокировки: долгое нажатие на экран блокировки, **Настроить**, добавить виджет Scriptable, затем выбери скрипт так же, как в шаге 5.

Виджет обновляется примерно раз в 5 минут. iOS сама решает, как часто его обновлять, поэтому время может отставать на пару минут.

## Как поменять расписание

Расписание лежит в начале файла, в блоке `SCHEDULE`. Дни недели: 1 = Пн, 2 = Вт, 3 = Ср, 4 = Чт, 5 = Пт.

```js
1: [
  { subject: "Matematika", room: "303", start: "09:00", end: "09:45" },
],
```

Сдвоенный урок записывается одним уроком: начало первой пары и конец второй. После правки снова скопируй файл в Scriptable.
